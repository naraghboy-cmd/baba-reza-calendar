# تقویم رویدادهای دامداری بابا رضا

نسخه اولیه پروژه اندروید با رابط فارسی و راست‌چین.

امکانات نسخه اولیه:
- ثبت تاریخ شمسی، ساعت و شماره پلاک
- وزن، جنسیت، نژاد، پلاک مادر و پدر، تاریخ تولد
- عنوان، نوع و توضیحات رویداد
- ذخیره محلی اطلاعات
- جستجوی سوابق بر اساس پلاک
- خروجی Excel (فرمت سازگار با Excel)
- خروجی PDF

برای ساخت APK، پروژه را با Android Studio باز کنید و Build > Build APKs را اجرا کنید.
